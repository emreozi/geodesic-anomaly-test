# geodesic-anomaly-test

Reference code and reproducibility materials for *Information-Geometric
Hypothesis Testing on the Categorical Statistical Manifold: A Geodesic Test
Statistic for Anomaly Detection in Decision Support Systems*.

The repository is organised as follows:

- `scripts/` contains the numerical experiments, analytic checks, and figure generators.
- `figures/` contains the ten vector figures used in the revised article.
- `data/derived/` contains a committed numerical summary and receives further
  summaries generated by the scripts.
- `bibliography/refs.bib` records the article references.

## Requirements and use

Python 3.10 or later is recommended. From the repository root, install the
dependencies and run the scripts:

```bash
python -m pip install -r requirements.txt
python scripts/audit_revision_math.py
python scripts/noncorr.py
python scripts/simulation.py
```

The principal script-to-output mapping is:

| Script | Main output |
| --- | --- |
| `simulation.py` | Null calibration, ROC, power, and geometry figures; `data/derived/results_summary.txt` |
| `curvature_sim.py` | Curvature figure; `data/derived/results_curvature.txt` |
| `noncorr.py` | Exact finite-sample coefficients printed to the terminal |
| `noncorr_fig.py` | Revised non-correctability figure |
| `composite_sim.py` | Composite-test figure; `data/derived/results_composite.txt` |
| `compbart_sim.py` | Composite mean-correction figure |
| `gauss_sim.py` | Gaussian-model figure |
| `nslkdd_experiment.py` | Real-data statistics; `data/nsl_results.npz` |
| `fig_nslkdd.py` | Real-data figure |

Run scripts from the repository root because their output paths are relative to
that directory. The simulation scripts use fixed random seeds. Full simulation
runs may take time; `noncorr.py` performs the long simulation only when called
with `--simulate`.

## External data

The NSL-KDD benchmark is not redistributed. To reproduce the real-data
experiment, obtain its `KDDTrain+_20Percent.txt` file and save it as
`data/nslkdd20.txt`; then run `nslkdd_experiment.py` and `fig_nslkdd.py`.
See `data/README.md` for details. The supplied `figures/fig_nslkdd.pdf` shows
the article figure without requiring the benchmark download.
