# Data

The NSL-KDD source data are not redistributed in this repository.

To reproduce the real-data experiment, obtain the public NSL-KDD 20% training
subset and save it as:

`data/nslkdd20.txt`

Running `scripts/nslkdd_experiment.py` creates `data/nsl_results.npz`. Both files
are excluded from version control.

Text summaries generated by the simulation scripts are stored under
`data/derived/` so that computed results do not clutter the project root.
